# edit - ShortsForge AI

**Next-Gen YouTube to Vertical Shorts AI Engine**

Transform long-form YouTube videos and local video uploads into high-retention 9:16 vertical viral shorts with AI speaker reframing, animated kinetic subtitles, smart audio synthesis, thumbnail studio, and full SEO metadata generation.

---

## ✨ Features

- **Automated YouTube Pipeline**: Enter any YouTube link or select from curated viral presets (Gaming, Challenges, Relatable, Storytelling).
- **Intelligent 9:16 Reframing**:
  - Center Speaker Tracking
  - Dynamic Left & Right Speaker Cropping
  - Split-Screen (Facecam + Gameplay / Satisfying B-Roll)
  - Bokeh Side-Blur
- **Kinetic Subtitle Presets**:
  - Alex Hormozi (Neon Yellow Glow + Bounce)
  - MrBeast (Bold Tilt + Lime Green / Yellow)
  - Cyberpunk (Monospaced Glitch Neon)
  - Minimal (Subtle Frosted Pill)
  - Red Alert (Emergency Flash)
- **Audio & SFX Studio**:
  - Procedural Web Audio tension risers, heartbeat sub-bass, and lo-fi tracks
  - Built-in sound effects (Whoosh, Ding, Pop)
- **High-CTR Thumbnail Studio**:
  - Dynamic 9:16 canvas thumbnail generator
  - Contrast boost, customizable headlines, subtext pills, and badges
- **SEO & Viral Metadata**:
  - Curated viral titles with 1-click clipboard copy
  - Optimized descriptions & hashtags
- **Instant Client-Side & Backend Export**:
  - Canvas MediaRecorder streaming export
  - High-Definition H.264 MP4 downloads

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- FFmpeg (for server-side video transcoding)

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/nishu90566-eng/edit.git
   cd edit
   ```

2. Start the local server:
   ```bash
   python3 server.py
   ```

3. Open in your browser:
   ```
   http://localhost:8080/
   ```
